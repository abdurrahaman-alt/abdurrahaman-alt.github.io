IoT-Based Home Automation System

ASSET Skills Competition Project (3rd Place Winner)

Overview & Objectives

Developed a smart home automation system capable of controlling electrical appliances remotely via IoT protocols and local PLC/HMI dashboards. Engineered for energy efficiency, safety monitoring, and automated load control.

Key Features & Modules

  • Multi-node relay control interface for AC appliances.
  • Real-time sensor monitoring (Temperature, Gas leakage, Motion detection).
  • Integrated HMI & Cloud IoT dashboard for remote operation.
  • Failsafe circuit breakers and manual override protection.
