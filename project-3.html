Crossroad Traffic Control System

PLC Programming & TIA Portal Implementation

Overview & Objectives

Developed an advanced PLC-based crossroad traffic control program using TIA Portal to optimize vehicle flow, manage signal intervals for multi-directional lanes, and enhance urban road safety.

Key Features & Logic

  • Sequential Red, Yellow, and Green signal timing configuration.
  • Timer and counter-based ladder logic implementation.
  • Emergency override mode and pedestrian crossing integration.
  • Virtual simulation and debugging via TIA Portal.
